# Kokedera for Warp

Copy the `.yaml` files into the themes directory for your platform:

- macOS: `~/.warp/themes/`
- Linux: `${XDG_DATA_HOME:-$HOME/.local/share}/warp-terminal/themes/`
- Windows: `%APPDATA%\warp\Warp\data\themes\`

Restart Warp if needed, open **Settings → Appearance**, and choose a Kokedera theme. The YAML sets terminal colors plus the UI accent and appropriate lighter/darker UI details. Selection rendering is managed by Warp.

## Variants

Kokedera Dusk (dark), Kokedera Morning (light), Kokedera Night (dark), Kokedera Spring (dark), Kokedera Summer (dark), Kokedera Autumn (dark), Kokedera Winter (light), Kokedera Rain (dark), Kokedera Mist (dark).

All formats use the same shared 16-color ANSI palette, foreground and background for each variant. Application-specific cursor, selection and UI behavior may differ.
